# 星空馆背景说明

## 交互

| 操作 | 效果 |
|------|------|
| 拖拽（鼠标） | 平移天球 |
| Ctrl / ⌘ + 滚轮 | 缩放（20°–140° 视场） |
| 双击 | 复位到初始视角 |
| 单击空白处 | 在该位置召唤流星雨 |
| **单击星座连线** | 弹出该星座的介绍卡（中文名 / 英文名 / 坐标 / 主要亮星 / 简介） |
| 关闭介绍卡 | 右上角 ✕、按 **Esc**、或点击空白处 |
| 触屏双指拖动 / 捏合 | 平移 / 缩放 |
| 触屏单指轻点 | 召唤流星雨 |
| **S** | 进入 / 退出纯净模式（只留星空） |
| **Esc** | 退出纯净模式 |

左下角 HUD 显示当前赤经 / 赤纬 / 视场角，`✦` 按钮可展开或收起。

### 可调节项（HUD 上的三个按钮）

| 按钮 | 档位 | 说明 |
|------|------|------|
| 自转 | 关 / 慢 / 中 / 快 | 待机 3.5 秒后开始转动；慢 0.4°/s、中 1.5°/s、快 4°/s |
| 流星 | 关 / 低 / 中 / 高 | 随机流星雨频率：低 70–150s、中 30–70s、高 12–30s，位置与规模随机 |
| 纯净 | 开 / 关 | 隐藏导航、正文、页脚，只保留星空 |

三个档位保存在 `localStorage`（键 `club.sky.settings`），刷新后保持。

调试时可加地址参数直接跳到某个天区：`?sky=83,0,45`（赤经 83°、赤纬 0°、视场 45°，即猎户座一带）。

## 文件

| 文件 | 说明 |
|------|------|
| `static/sky/sky.json` | 精简后的星表 + 星座连线（约 146 KB，gzip 48 KB） |
| `static/sky/sky.js` | 渲染与交互（球极投影、拖拽、缩放、流星雨） |
| `scripts/build_sky_data.py` | 把原始星表压成上述 JSON |
| `scripts/data/` | 原始数据（不参与部署） |
| `scripts/data/constellation_info.json` | 88 星座的中文简介与主要亮星（手写） |

## 数据来源与许可

- 恒星：HYG Database（CC BY-SA 4.0），经 d3-celestial 整理的 `stars.6.json`（mag ≤ 6，5044 颗）
- 星座连线 / 名称：d3-celestial（BSD-3-Clause），88 星座、743 条线段，含中文名
- 页脚已注明来源

## 重新生成数据

```powershell
python scripts/build_sky_data.py
```

原始文件（`scripts/data/`）从 npm 包 `d3-celestial@0.7.35` 的 `data/` 目录获取：

- `stars.6.json`
- `constellations.lines.json`
- `constellations.json`

## 性能取舍

- 低端机（`deviceMemory ≤ 4` 或 `hardwareConcurrency ≤ 4`）自动把星等限制到 5.2、DPR 上限 1.25
- 星点只在视角变化时重绘；流星画在独立的 `#sky-fx` 图层，不触发星空重绘
- 悬停命中测试节流到 60ms，只对 743 条线段做距离计算
- 遵守 `prefers-reduced-motion`：不生成环境流星

## 已知限制

- 未做岁差/自行/时角，画面是固定的赤道坐标星图，不随真实时间转动
- 没有银河、深空天体、行星
- 星座连线为西方传统连线，不是中国星官体系
- 星座简介是人工撰写的科普性内容（本地文件，不依赖外部 API），不是专业天文数据
